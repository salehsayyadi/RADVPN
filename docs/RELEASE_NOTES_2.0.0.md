# RADVPN 2.0.0 — release candidate notes (not published)

Native Windows/Android client with an embedded, pinned Xray engine, Tunnel-default selection, loopback SOCKS5/HTTP, English/Persian UI, secure vaults, configuration import, profiles, subscriptions and real connectivity/counter handling.

**These are draft notes, not a public release.** See TESTING.md for commands actually run and KNOWN_LIMITATIONS.md for gaps. No tag or production signing claim is made. Device TUN, leak, crash/recovery and remote-server acceptance must pass before publication. Only artifacts built from the approved final commit and actually tested may be attached. Debug APKs must be explicitly labeled testing/debug signed; no production AAB is provided without configured signing credentials.
